# طلاقة (Talaqa): تطبيق iOS لتعليم الإنجليزية

تطبيق SwiftUI أصلي (iOS 17 وما بعده) لتعليم الإنجليزية للناطقين بالعربية.

## المزايا

| القسم | ما يقدّمه |
|---|---|
| اختبار تحديد المستوى | اختبار تكيّفي من 15 سؤالاً يحدّد مستواك من A1 إلى C2 |
| خطة اليوم | خطة يومية تُبنى تلقائياً من مستواك ووقتك وما أنجزته |
| المفردات | تكرار متباعد بخوارزمية **FSRS-5**، وبطاقات للتعرّف وأخرى للكتابة (استرجاع نشط)، ونطق صوتي، ولكل كلمة مثال وترجمة |
| القواعد | 14 درساً من A1 إلى C1، شرح بالعربية، تنبيهات لأخطاء العرب الشائعة، وتمارين اختيار وإكمال وترتيب كلمات |
| المعلّم الذكي (Claude) | محادثات في 12 موقفاً واقعياً (مقهى، مقابلة عمل، IELTS…)، تصحيح تحت كل رسالة، إدخال صوتي، واقتراح رد |
| مدرّب الكتابة | تقييم من 100، والمستوى التقديري، وقائمة بالأخطاء، والنص مصحّحاً، ونسخة أكثر طلاقة |
| النطق (Shadowing) | 8 مجموعات لأصوات صعبة على العرب (p/b، v/f، th…) مع تقييم كلمة بكلمة |
| القراءة | قصص متدرّجة، اضغط على أي كلمة لتسمعها، أضف الكلمات لبطاقاتك، وأسئلة فهم |
| أخطائي | كل خطأ يُحفظ، ويمكنك مراجعته مع المعلّم الذكي |
| التقدّم | XP، وسلسلة أيام، ورسم بياني أسبوعي، ودقّة كل مهارة، وتذكير يومي |

## الحصول على ملف IPA بدون جهاز Mac

1. ارفع هذا المجلد إلى مستودع على GitHub (فرع `main`).
2. يبني GitHub Actions المشروع تلقائياً (`.github/workflows/build-ipa.yml`) على جهاز macOS.
3. افتح: **Actions ← Build IPA ← آخر تشغيل ← Artifacts** ونزّل `Talaqa-unsigned-ipa`.

ملف IPA يخرج **غير موقّع**، فوقّعه أثناء التثبيت بإحدى الطرق:

- **Sideloadly** أو **AltStore**: تسجّل بـ Apple ID مجاني ثم تثبّت الملف. التوقيع المجاني صالح 7 أيام ثم تعيد التوقيع.
- **حساب Apple Developer (99$/سنة)**: صالح سنة كاملة ويتيح TestFlight والنشر على App Store.

## البناء على جهاز Mac

```bash
brew install xcodegen
```

```bash
xcodegen generate && open Talaqa.xcodeproj
```

اختر فريقك من Signing & Capabilities ثم شغّل التطبيق على جهازك.

## تفعيل المعلّم الذكي

من التطبيق: **حسابي ← الإعدادات ← المعلّم الذكي**، وهناك خياران:

- **للاستخدام الشخصي**: ألصق مفتاح Claude API، ويُحفظ في Keychain على جهازك فقط.
- **للتوزيع على الآخرين**: انشر `server/worker.js` على Cloudflare Workers وضع رابطه في التطبيق، حتى لا يكون المفتاح داخل التطبيق.

النموذج الافتراضي `claude-opus-5-5`، ويمكن اختيار Sonnet 5.5 أو Haiku 5.5 من الإعدادات.

## تعديل المحتوى

المحتوى في `tools/content_*.py`. بعد التعديل شغّل:

```bash
python3 tools/build_content.py
```

## البنية

```
Talaqa/
  App/          نقطة الدخول والتبويبات
  Models/       نماذج SwiftData وأنواع المحتوى
  Engine/       FSRS، اختبار المستوى، مطابقة النطق، مخطّط اليوم
  Services/     المحتوى، الصوت، Claude API، الإشعارات، التقدّم
  Views/        الشاشات
  Resources/    ملفات JSON والأيقونة
server/         خادم وسيط (Cloudflare Worker)
tools/          مولّد المحتوى
```
